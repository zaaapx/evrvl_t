# EVRVL — гостиничная недвижимость на Бали

Одностраничный сайт (десктоп + мобильная версия).

## Структура
- `index.html` — страница (шаблон + логика)
- `support.js` — рантайм (React, рендер шаблона)
- `assets/` — изображения (WebP) и логотипы (SVG)
- `fonts/` — фирменные шрифты HeadingNow

## Запуск
Статический сайт — достаточно любого HTTP-сервера:

```
npx serve .
```

Работает на GitHub Pages без настройки (Settings → Pages → deploy from branch).
