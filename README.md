# EVERVILLE — сайт

Статический сайт (Design Components, без сборки). Открывается с index.html.

## Страницы
| Файл | Страница |
| --- | --- |
| index.html | Главная (desktop + tablet + mobile) |
| projects.html / projects-tablet.html / projects-mobile.html | Проекты (авторедирект по ширине экрана) |
| roya.html / roya-tablet.html / roya-mobile.html | ROYA Resort (авторедирект по ширине экрана) |
| investments.html | Инвестиции |
| legal.html | Юридика (due diligence) |
| about.html | О компании |
| contacts.html | Контакты |
| legal-privacy.html | Политика конфиденциальности |
| legal-terms.html | Пользовательское соглашение |
| legal-disclaimer.html | Инвестиционный дисклеймер |

## Функциональность
- Кнопка «Инвестировать» и CTA-кнопки открывают поп-ап с формой (имя, e-mail, телефон — обязательные, с валидацией)
- «Войти» → https://portal.everville.estate/login
- Футер единый на всех страницах: Проекты / Инвестору / Legal / Контакты

## Публикация на GitHub Pages
Залейте содержимое папки в репозиторий и включите Pages (branch root). Точка входа — index.html.
