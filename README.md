# EVERVILLE — сайт

Статический сайт (Design Components, без сборки). Точка входа — `index.html`.

## Структура
Каждая страница в трёх версиях: `slug.html` (desktop), `slug-tablet.html`, `slug-mobile.html`.
При открытии выполняется авторедирект на версию под ширину экрана (<768 — mobile, 768–1023 — tablet, ≥1024 — desktop).

| Слаг | Страница |
| --- | --- |
| index | Главная |
| projects | Проекты |
| balicopter, marina, roya, roya-desa, sanatorium | Страницы проектов |
| investments | Инвестиции |
| legal | Юридика (due diligence) |
| about | О компании |
| contacts | Контакты |
| legal-terms / legal-privacy / legal-disclaimer | Правовые документы |
| 404 | Страница не найдена |

## Функциональность
- «Инвестировать» и CTA открывают поп-ап с формой (валидация на клиенте; поля очищаются после успешной отправки)
- «Войти» → https://portal.everville.estate/login
- Ленивая загрузка изображений и видео, единый футер с видеофоном

## Архив
`archive/2026-08-26/` — предыдущая версия сайта (снимок main до этого обновления). Открывается автономно; видео футера берёт из корневых assets.

## Публикация на GitHub Pages
Залейте содержимое папки в репозиторий и включите Pages (branch root). `404.html` в корне GitHub Pages подхватывает автоматически как страницу ошибки.
